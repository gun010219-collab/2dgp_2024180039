애니메이션 뷰어 기획 초안

pico2d를 사용. python 쓴다.
단일 파일로 만든다. 이름은 sonic_animation_viewer.py
이미 사용하는 sprite sheet는 sonic-sprite.png

기능:
스프라이트 sheet에 담겨있는 모든 애니메이션을 재생한다.
한 동작의 애니메이션을 5번 반복 재생하고, 1초 쉬고, 그 다음 동작으로 간다.
전체 애니메이션 재생이 끝나면, 다시 무한 반복한다.
이미지의 크기는 화면에서 잘 보이도록 확대한다.

구현절차:
한번에 모든 코드를 작성하지 말고, 단계별로 작성해서, 최소한 20번 이상의 커밋이 되도록 한다.

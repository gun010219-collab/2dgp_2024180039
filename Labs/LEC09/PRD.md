# PRD: Sonic 애니메이션 뷰어

## 1. 제품 개요

### 1.1 목적

`pico2d`와 Python을 사용해 제공된 Sonic 스프라이트 시트의 애니메이션을 순서대로 재생하는 데스크톱 뷰어를 만든다. 별도의 입력 없이 모든 애니메이션을 반복해서 확인할 수 있어야 한다.

### 1.2 대상 사용자

- 스프라이트 시트에 포함된 Sonic 애니메이션을 한 화면에서 확인하려는 사용자
- `pico2d`를 이용한 2D 애니메이션 구현을 학습하는 개발자

### 1.3 대상 플랫폼 및 파일

| 항목 | 요구사항 |
|---|---|
| 언어 | Python |
| 그래픽 라이브러리 | pico2d |
| 실행 파일 | `sonic_animation_viewer.py` |
| 입력 에셋 | `sonic-sprite.png` |
| 구현 형태 | 단일 Python 파일 |

스프라이트 이미지는 실행 파일과 함께 제공되는 `sonic-sprite.png`를 사용한다. 다른 외부 이미지나 애니메이션 에셋은 범위에 포함하지 않는다.

## 2. 목표 및 범위

### 2.1 목표

1. 스프라이트 시트에 담긴 모든 애니메이션 시퀀스를 식별하고 재생한다.
2. 각 시퀀스를 5회 연속 재생한 후 1초간 대기하고 다음 시퀀스로 넘어간다.
3. 마지막 시퀀스까지 재생하면 첫 시퀀스로 돌아가 전체 순서를 무한 반복한다.
4. 캐릭터가 화면에서 잘 보이도록 원본보다 확대해 표시한다.

### 2.2 범위 제외

- 애니메이션 선택, 일시 정지, 속도 조절 등의 사용자 조작 UI
- 스프라이트 시트 편집 또는 외부 에셋 다운로드
- 여러 캐릭터나 여러 스프라이트 시트를 지원하는 기능
- 애니메이션 결과의 파일 저장 및 동영상 녹화

## 3. 사용자 흐름

1. 사용자가 `sonic_animation_viewer.py`를 실행한다.
2. 프로그램이 pico2d 화면을 열고 `sonic-sprite.png`를 불러온다.
3. 첫 애니메이션 시퀀스를 재생한다.
4. 해당 시퀀스를 총 5회 재생하고 1초간 대기한다.
5. 다음 시퀀스에 대해 같은 절차를 반복한다.
6. 마지막 시퀀스가 끝나면 첫 시퀀스부터 다시 시작한다.
7. 사용자가 창을 닫으면 프로그램이 정상 종료된다.

## 4. 기능 요구사항

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-01 | 프로그램은 `sonic-sprite.png`를 불러와야 한다. | 필수 |
| FR-02 | 프로그램은 시트에 포함된 모든 애니메이션 시퀀스를 재생 순서에 포함해야 한다. 시트의 장식 문구나 단독 이미지처럼 애니메이션 프레임이 아닌 요소는 재생 대상이 아니다. | 필수 |
| FR-03 | 한 시퀀스의 프레임을 지정된 프레임 순서대로 연속 재생해야 한다. | 필수 |
| FR-04 | 각 시퀀스를 정확히 5회 반복한 뒤 다음 시퀀스로 이동해야 한다. | 필수 |
| FR-05 | 시퀀스 재생이 끝난 뒤 다음 시퀀스가 시작되기 전까지 1초간 대기해야 한다. 마지막 시퀀스 뒤에도 같은 대기 시간을 적용한 후 첫 시퀀스로 돌아간다. | 필수 |
| FR-06 | 모든 시퀀스 재생을 중단 없이 무한 반복해야 한다. | 필수 |
| FR-07 | 캐릭터를 원본보다 확대해 표시하고, 프레임이 화면 경계에서 잘리지 않도록 해야 한다. | 필수 |
| FR-08 | 창 닫기 동작으로 그래픽 리소스를 정리하고 프로그램을 종료해야 한다. | 필수 |

## 5. 화면 및 재생 동작

- 창 크기와 배경색은 구현 시 화면 구성이 명확하고 캐릭터가 식별되도록 정한다.
- 확대 표시 시 원본의 가로세로 비율을 유지하고 프레임이 화면 안에 들어오도록 배치한다.
- 프레임 재생은 프레임마다 일정한 시간 간격으로 진행한다. 구체적인 프레임 속도(FPS)는 스프라이트 동작을 알아보기 쉬운 값으로 구현 단계에서 정한다.
- 재생 중인 시퀀스의 순서는 스프라이트 시트의 배치와 동작을 확인해 결정하며, 시트에 있는 모든 애니메이션을 누락 없이 목록화한다.
- 시트에 애니메이션 시퀀스 구분 또는 프레임 좌표 정보가 별도로 제공되지 않으므로, 구현자는 시트의 프레임 경계와 시퀀스 구성을 확인해야 한다. 불명확한 프레임 분할은 임의로 추정해 누락하거나 섞지 말고, 시각적 검토가 가능하도록 시퀀스 매핑을 명확하게 정리한다.

## 6. 비기능 요구사항

- **단순성:** 실행 및 재생에 필요한 로직은 `sonic_animation_viewer.py` 한 파일에 둔다.
- **안정성:** 재생은 프레임 단위 시간 관리로 수행하며, 대기 중에도 창 이벤트 처리가 멈추지 않아야 한다.
- **에셋 경로:** 에셋 경로는 실행 위치에 과도하게 의존하지 않도록 프로젝트 내 파일 배치를 기준으로 결정한다.
- **종료 처리:** 프로그램 종료 시 pico2d가 연 그래픽 리소스를 정상적으로 닫는다.

## 7. 검수 기준

1. 프로젝트의 `Labs/LEC09` 폴더에서 프로그램을 실행하면 pico2d 창이 열리고 `sonic-sprite.png`가 표시된다.
2. 시트에 확인되는 모든 애니메이션 시퀀스가 정해진 순서로 최소 한 번 이상 재생된다.
3. 임의의 시퀀스를 관찰했을 때 프레임이 5회 재생된 다음, 다음 시퀀스로 이동하기 전 1초간 멈춘다.
4. 마지막 시퀀스 이후 1초 대기 후 첫 시퀀스가 다시 시작되고, 재생이 계속 반복된다.
5. 캐릭터가 원본보다 크게 보이며, 확대된 프레임의 일부가 화면 밖으로 잘리지 않는다.
6. 실행 중 창을 닫았을 때 오류 없이 종료된다.
7. 실행에 필요한 Python 구현은 `sonic_animation_viewer.py` 단일 파일로 제공된다.

## 8. 구현 및 개발 절차

- 한 번에 전체 코드를 작성하지 않고, 실행 가능한 작은 단위로 기능을 단계적으로 구현한다.
- 초안의 개발 절차 요구에 따라 작업 과정을 최소 20회 이상의 커밋으로 나눈다. 커밋은 기능 추가, 동작 검증, 오류 수정 등 실제 변경 단위로 구성하며, 의미 없는 커밋 분할은 피한다.
- 구현 단계에서 최소한 에셋 로드, 단일 시퀀스 재생, 5회 반복, 1초 대기, 전체 순환, 종료 처리를 각각 확인한다.
- 커밋 수는 Git 이력에서 확인하고, 기능 검수는 이 문서의 검수 기준에 따라 수행한다.

## 9. 가정 및 미결 사항

- `pico2d`는 실행 환경에 설치되어 있다고 가정한다.
- `sonic-sprite.png`는 프로젝트의 `Labs/LEC09` 디렉터리에 제공된다.
- 프레임 속도, 창 크기, 배경색 및 시퀀스의 구체적인 순서는 초안에 지정되어 있지 않다. 구현자는 재생 가독성과 시트의 실제 프레임 배치를 확인해 정하고, 모든 시퀀스가 누락되지 않았는지 검수한다.
